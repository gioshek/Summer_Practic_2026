# Контрольный список разметки

Перед завершением каждого изображения проверить:

- [ ] Каждая видимая конфета имеет отдельную рамку.
- [ ] Несколько конфет не объединены одной рамкой.
- [ ] Все различимые конфеты в плотных кучах учтены.
- [ ] Конфеты на границе кадра учтены.
- [ ] Для `wrapped` рамка включает относящуюся к конфете обёртку.
- [ ] Для `unwrapped` рамка охватывает открытую конфету.
- [ ] Белый калибровочный стикер не размечен.
- [ ] Хвосты обёртки не размечены отдельными объектами.
- [ ] Грязь, блики, царапины и фон не размечены.
- [ ] Рамки не содержат слишком много пустого фона.
- [ ] Классы `wrapped` и `unwrapped` не перепутаны.
- [ ] Неоднозначные случаи записаны в `annotation_decisions.csv`.
- [ ] Изображение помечено как проверенное только после повторного просмотра.

## Быстрая проверка класса

### `wrapped`

- виден упаковочный материал;
- видны края или хвосты обёртки;
- конфета выглядит упакованной.

### `unwrapped`

- видна открытая поверхность конфеты;
- нормальная обёртка отсутствует;
- конфета раскрыта или частично лишена обёртки.

## Запрещено

- угадывать класс;
- объединять несколько конфет;
- размечать белый стикер;
- размечать хвост фантика отдельно;
- оставлять очевидную конфету без рамки.
