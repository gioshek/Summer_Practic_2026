# Candy Quality Control

Проект производственной практики по контролю качества упаковки конфетной продукции на изображениях, полученных при фронтальном освещении.

## Задача

Программа должна:

- обнаруживать все различимые конфеты, включая частично попавшие в кадр;
- классифицировать конфеты на `wrapped` и `unwrapped`;
- считать общее количество объектов и количество объектов каждого класса;
- вычислять процент брака;
- не учитывать фон, загрязнения и белый калибровочный стикер.

Класс `wrapped` соответствует конфете в обёртке и считается небракованным. Класс `unwrapped` соответствует конфете без обёртки и считается бракованным.

## Ветки проекта

- [`main`](https://github.com/gioshek/Summer_Practic_2026/tree/main) — архив исходных изображений и краткое описание проекта. Исходные данные находятся в `data/raw/frontlight/`.
- [`feature/yolov8`](https://github.com/gioshek/Summer_Practic_2026/tree/feature/yolov8) — основная рабочая и итоговая версия проекта. В ней находятся подготовка разметки, обучение моделей YOLOv8n на выборках D23 и D50, независимая оценка качества и итоговый детектор.
- [`practice/current-prototype`](https://github.com/gioshek/Summer_Practic_2026/tree/practice/current-prototype) — предварительный алгоритмический прототип на основе OpenCV, морфологических операций, пиксельной классификации и алгоритма водораздела. Этот вариант не используется как итоговый, поскольку недостаточно устойчиво разделяет плотные группы конфет и зависит от условий освещения.

## Архив исходных данных

В ветке `main` хранится полный исходный набор изображений:

```text
data/raw/frontlight/
├── basler_120126/
├── basler_OldObj/
├── basler_tstRGB/
└── images/
```

Набор включает 594 изображения в формате BMP общим объёмом около 5,6 ГБ. Большие файлы хранятся с использованием Git LFS.

После клонирования репозитория для загрузки исходных изображений необходимо выполнить:

```bash
git lfs install
git lfs pull
```
